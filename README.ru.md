# claude-telegram-orchestrator

**Персональный AI-ассистент, живущий в Telegram.** Бот — это слой транспорта и
управления; движок — долгоживущий агент **Claude Code** (`claude -p`), внутри которого
происходит всё рассуждение и работа с инструментами. Собран и обкатан за ~2 месяца
ежедневного использования, работает на VPS и Mac в синхроне и обслуживает несколько
отдельных людей из одного общего пула навыков.

Сложное здесь — не «отправить сообщение в Telegram», а удержать долгоживущего агента
**быстрым** (резидентный процесс на каждый чат), **честным и в фокусе** (слой крюков,
чинящих дрейф модели), **заземлённым** (смысловой поиск по личной базе знаний),
**устойчивым** (файловая долговременная память и двусторонняя синхра Mac↔VPS) и
**функциональным** (своя Telegram-инфраструктура, браузерный мост, голос, календарь,
фоновые задачи).

> Claude Code — это зависимость (движок), а не часть репозитория. Здесь —
> **портфолио-выгрузка** рабочего персонального ассистента, все личные данные удалены —
> имена, пути, кабинеты и секреты заменены заглушками или читаются из окружения.
> Включает оркестратор, движок поиска, крюки дисциплины, пул навыков, образцы
> инфраструктуры и скелет vault.

## Что в этом репозитории

| Файл | Что это |
| --- | --- |
| `resident_claude.py` | Обёртка движка: один долгоживущий процесс `claude -p --input-format stream-json` со сторожевым таймером (watchdog) и «догоном» через прерывание протокола. |
| `bot.py` | **Минимальный** оркестратор (~150 строк) — главный цикл в самом ясном виде: long-poll, один резидент на чат, потоковая отдача ответа. С него удобно начать чтение. |
| `tg_bot.py` | **Полный** бот — вложения, маркеры ответа, отправка медиа/голоса, разбивка длинных сообщений, инлайн-меню, расшифровка голоса, календарь, фоновые задачи. |
| `deep_research/` | Браузерный мост: гоняет стелс-браузер на сервере, чтобы использовать функцию «Deep Research», которая есть только в веб-интерфейсе, и читает результат обратно. |
| `prompts/system_prompt.example.md` | Обезличенный пример системного промпта — *форма* правил без личного содержания. |
| `transcribe_native.py` | Расшифровка голоса через Premium-сессию пользователя Telegram (быстро, без нагрузки на CPU сервера). |
| `vault_rag/` | Движок смыслового поиска по базе знаний — гибридный (вектор + полный текст), локальный, без GPU, с прогретым демоном. См. отдельный README. |
| `hooks/` | ~30 крюков Claude Code — слой дисциплины, чинящий дрейф модели (честность, заземление, краткость, проверка плана, аудит) плюс крюки безопасности и синхры. |
| `skills/` | 53 навыка (слэш-команды) — пул возможностей ассистента, обезличенный. |
| `infra/` | Образцы развёртывания: свой Telegram Bot API server (Docker), systemd-юниты, faster-whisper shim расшифровки, скрипт синхры Mac↔сервер. |
| `vault_example/` | Обезличенный скелет базы знаний, на которой работает ассистент (структура + правила, без содержания). |

## Полный список функций

### Движок и сессии
- **Резидентный процесс на каждый чат.** Один процесс `claude -p` держится живым на
  разговор; холодный старт (~6с) платится один раз, последующие ходы пропускают
  загрузку Node + бинарника + MCP. (`resident_claude.py`)
- **Догон через прерывание протокола.** Новое сообщение посреди ответа прерывает
  текущий ход (не убивает) и стартует новый ход на том же процессе, сохраняя историю.
- **Сторожевые таймауты.** Поток-сторож убивает процесс по таймауту хода или тишины —
  зависший вызов инструмента не может подвесить бота.
- **Инлайн-кнопка «⏹ Стоп»**, появляется до старта хода и чисто убивает процесс,
  сохраняя накопленный текст.
- **Потоковый вывод.** Ответ появляется по мере генерации в status-сообщении (с
  троттлингом), а не одним финальным куском.
- **Фоновые задачи (`__BG_TASK__`).** Долгие задачи идут в потоке-стороже; по
  завершении бот открывает *отдельный* ход с результатом и пишет пользователю первым —
  не блокируя живой чат.
- **Ротация сессий и учёт токенов.** Хранилище сессий на чат; со временем сам
  предлагает `/compact`; счётчик токенов по трём горизонтам (сессия / ход / сообщение).
- **Режим TTL при лимите квоты.** При достижении лимита Claude бот тихо складывает
  входящее в inbox с реакцией 👀 вместо ошибки.

### Память и правила (почин дрейфа модели)
- **Файловая долговременная память.** Папка `memory/` из заметок `feedback_*` /
  `project_*` с индексом, которые агент читает и пишет — знание, переживающее сессии,
  своё на каждый инстанс.
- **«Конституция» из файлов поведения** (`SOUL.md`, `principles.md`, `autonomy.md`,
  `audit-mode.md`), задающих голос, правила, разрешения и оптику аудита.
- **Горячая перезагрузка правил — без перезапуска.** Бот следит за файлами правил и
  промпта; при изменении подсовывает diff в начало следующего хода и помечает «правила
  обновились», не разрывая нить в Telegram.
- **Крюки дисциплины, чинящие дрейф модели.** Слой крюков держит агента честным и в
  фокусе, каждый стреляет по триггерам и подсовывает указание: `honesty-gate`
  (метить факты / не выдумывать), `ground-truth-gate` (проверить источник до
  утверждения, не отвечать по памяти), `terse-gate` (быть кратким),
  `simple-language-gate` (простой язык + глоссарий), `verify-plan-gate` (требовать план
  + подтверждение до правок), `audit-gate` (подтолкнуть к аудиту перед архитектурным
  решением). Плюс крюки безопасности (`safety.sh` блокирует опасный shell,
  `tg-write-gate` гейтит исходящие сообщения), `precompact-backup`,
  `auto-commit-flush` и другие — всего ~30 крюков.

### Смысловой поиск (RAG по vault)
- **Гибридный поиск по базе знаний.** Семантический (мультиязычный эмбеддер MiniLM
  через `fastembed`, без GPU и внешних API) + полнотекстовый (`SQLite FTS5`), слияние
  через reciprocal-rank fusion; выдача `файл:строка`, под ~0.6с.
- **Прогретый демон**, который держит модель загруженной, выгружает после простоя и
  отвечает на команды `search` / `reindex`; автозапуск через systemd (VPS) / launchd
  (Mac).
- **Переиндексация после каждого сообщения**, а не перед каждым поиском — поэтому поиск
  всегда мгновенный и не платит лаг пересборки пачкой.
- **Логи чатов тоже индексируются** — разговоры самого бота дописываются в индекс,
  так что «что мы обсуждали про X» находится поиском.

### Синхронизация Mac ↔ VPS
- **Двусторонняя синхра вокруг каждого сообщения.** Транспорт — bare git-репозиторий;
  VPS-бот синхронится в начале каждого хода, Mac симметрично зеркалит через крюк — ни
  одна сторона не теряет работу при некорректном выходе.
- **Спасательный коммит** перед каждым fetch/merge, чтобы прерванная сессия не уронила
  файлы.
- **Ежечасный самобэкап** исходника бота в vault (read-only зеркало).
- **Раздельные лог-файлы по машинам**, чтобы два инстанса не затирали лог одного дня;
  оба индексируются для поиска.

### Telegram-инфраструктура (собрана, не из коробки)
- **Свой Telegram Bot API server** (local-режим, `127.0.0.1`) — поднимает лимит файлов
  с 20 МБ до **2 ГБ**; один сервер обслуживает несколько ботов, различая их по токену.
- **Свой MCP Telegram server** — Telethon user-сессия, умеющая писать в *любой* чат от
  имени владельца, слать голос / файлы / реакции, править и удалять сообщения — за
  пределами Bot API-ограничения «только тот, кто написал первым». Исходящие записи
  гейтируются крюком.
- **Расшифровка голоса несколькими путями** — по длине записи: родная Premium-сессия
  Telegram (не зависит от длины, без CPU сервера; `transcribe_native.py`),
  опциональный локальный faster-whisper-shim для коротких, и AssemblyAI для длинных, с
  авто-fallback.
- **Синтез речи (`__TTS__`).** Голос выбирает модель; маршрут на zvukogram / edge-tts.
- **Google Calendar (MCP).** Двухстадийное создание события (`__CAL_PROPOSE__` →
  подтвердить → создать), события на весь день, отложенное состояние с TTL.
- **Вложения.** Авто-сохранение фото/видео/документов/аудио в vault, агрегация
  альбомов, очередь подтверждения/сброса, 30-дневный архив голосовых.
- **Медиа-ответы.** Пути к файлам из ответа уходят обратно как фото или документы;
  длинные сообщения режутся под лимит Telegram с рендерингом Markdown→HTML.
- **Инлайн-меню навигации** по брифам/проектам с обработкой нажатий.
- **Планировщик-агенты** через systemd-таймеры (МСК): дневной бриф, рефлексия,
  еженедельная ревизия.
- **Развёртывание копий для других людей** — шаблон клонирует весь бот (новый
  пользователь + скелет vault + чистые файлы правил) на тот же общий пул навыков.

### Внешние интеграции и инструментарий (пул навыков)
Ассистент несёт **53 навыка** (слэш-команд). Ключевое:
- **Браузерная автоматизация на сервере** — стелс-браузер (patchright + Chrome под
  Xvfb) обходит Cloudflare для парсинга и для функций из веб-интерфейса
  (`deep_research/`).
- **Стягивание и расшифровка записей звонков** — вход в веб-кабинет оператора связи,
  забор MP3-записей, расшифровка с разметкой по ролям (AssemblyAI).
- **Парсеры афиш / расписаний** — разбор расписаний кинотеатров, фильтр и отчёт по
  расписанию.
- **Стягивание медиа** — Instagram reels (через Apify) и YouTube (субтитры / кадры /
  звук).
- **Генерация контента и карточек** — карточки товаров, фотосъёмка, генерация
  афиш/постеров, генерация изображений/видео.
- **Воронка vault** — захват inbox-first, `/process-inbox`, `/atomize`,
  `/weekly-review`, `/daily-prep` и трёхагентный `/audit` (vault + web + challenger)
  перед архитектурными решениями.

## Запуск

**Минимальный бот** (`bot.py`) говорит со стандартным API Telegram и заводится из
коробки — с него удобно начать:

```bash
cp .env.example .env                 # задай хотя бы TELEGRAM_BOT_TOKEN + TELEGRAM_ALLOWLIST
pip install -r requirements.txt
set -a; source .env; set +a
python bot.py
```

Нужны: бинарник `claude` в PATH (движок) и токен бота Telegram. Всё.

**Полный бот** (`tg_bot.py`) — продакшн-версия, требований больше:

- Говорит с **локальным Telegram Bot API server** (для файлов до 2 ГБ), а не напрямую
  с `api.telegram.org` — подними его первым из
  [`infra/docker-compose.bot-api.yml`](infra/docker-compose.bot-api.yml).
- Опциональные функции тянут доп. пакеты по месту (напр. `faster-whisper` для
  локального голосового shim) — см. `requirements.txt`.
- Смысловой поиск (`vault_rag/`) имеет свои зависимости и настройку — см.
  [`vault_rag/README.md`](vault_rag/README.md).

## Примечания

- Портфолио-выгрузка — точная обезличенная копия рабочего бота, не игрушка.
- Все пути и секреты читаются из окружения; см. `.env.example`.
