# Resources/ — the library (no operational state)

| Folder | What |
| --- | --- |
| `atoms/` | Zettelkasten notes — one idea each. `_`-prefixed files are maps-of-content or source cards. |
| `attachments/` | Media: `YYYY-MM-DD-<slug>.<ext>`. |
| `chat-logs/` | Conversation transcripts (`raw/` + `processed/`); the processed ones are indexed by `vault_rag/`. |
| `glossaries/` | Term dictionaries. |
| `_templates/` | Note templates (daily, weekly, monthly, project, atom). |

If something doesn't fit a subfolder, make a topic subfolder — don't dump it in the
root of `Resources/`.
