# Карта хранилища

| Раздел | Что внутри |
|---|---|
| `Projects/` | активная работа: по папке на проект (`manual.md` + `tasks.md` + `log.md`) |
| `Resources/` | библиотека: материалы, вложения, логи разговоров |
| `Tasks/` | правила работы (`manual.md`) и общие задачи (`tasks.md`) |
| `Journal/` | дневник по датам + `log.md` — хроника сессий |
| `Self/` | личность ассистента: как он говорит и держится |
| `inbox.md` | единая точка захвата: всё падает сюда, разбирается позже |
| `status.md` | что горит прямо сейчас — обновляется в конце каждой сессии |
